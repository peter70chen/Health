# 食物辨識基準測試

這個資料夾只存測試照片與人工確認的真值，不存正式每日紀錄。

1. 準備 40 至 60 組常見餐點，涵蓋單品、便當、混合餐、包裝標示與低光照片。
2. 每組由秤重或包裝營養標示建立 `groundTruth`。
3. 每個模型與 prompt 組合至少重跑 3 次，結果填入不提交 Git 的 `manifest.json`。
4. 執行 `npm run eval:food` 比較熱量 MAE / MAPE、系統性偏差、區間涵蓋率、格式成功率與延遲。
5. Pro 只有在低信心或混合餐的錯誤率穩定改善至少 5 個百分點，而且改善大於同模型重跑變異時，才適合自動啟用。

真實食物照片可能含個人環境資訊，`manifest.json` 與照片預設不應提交版本庫。
