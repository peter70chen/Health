# 食物辨識準確度改版實作報告

日期：2026-07-26

## 模型決策

- 正式預設：`gemini-3.6-flash`
- 同級備援：`gemini-3.5-flash`
- 精準複核候選：`gemini-3.1-pro-preview`
- Pro 功能旗標目前關閉。完成 40–60 組真實照片、每組至少三次的 A/B 基準測試，而且低信心或混合餐誤差穩定改善至少 5 個百分點後才開啟。
- App 內所有食物、飲水、運動、阻力與健康教練分析一律使用 Paid Key。Free Keys 只保留給不含個人資料的測試。

## 已完成

1. 食物分析改為正式 JSON Schema，加上 Zod 執行期驗證。
2. 混合餐逐項回傳重量 low / mid / high、每 100g 營養、來源、信心度與判斷依據。
3. 熱量與營養素由程式依重量決定式加總，不採用模型自行回傳的整餐總數。
4. 「照片可見份量」與「實際吃下比例」分離，避免只吃一半被折算兩次。
5. 結果卡可直接修改每一項食物的公克數，警告會即時重算。
6. 支援第二張角度照片與已知盤子／參考物尺寸。
7. 圖片會修正方向、縮小長邊並轉成 JPEG；只保留當次分析所需的記憶體資料，不寫入每日紀錄或備份。
8. 建立 362 筆 TFDA 台灣食品營養資料，僅允許正式名稱或唯一別名精確匹配。
9. 乾麵、生料、差異過大的 TFDA 數值不會覆寫熟食估算；歧義別名直接放棄匹配。
10. 低信心結果最多提出兩個問題，可回答後重新分析。
11. 記住使用者真正手動修正的分項重量；自動套用記憶不會被重複計為人工確認。
12. 保存模型原始營養、最終修正值、模型版本、prompt/schema 版本與分析時間，不保存照片。
13. 修正食物重量誤顯示為 ml；舊食物紀錄自動以 g 顯示，舊飲料衍生紀錄維持 ml。
14. 常用食物新增基準重量，備份與還原包含個人校正記憶。
15. 建立食物照片基準評估工具，可比較 MAE、MAPE、偏差、營養素誤差、重量誤差、區間涵蓋率、辨識率、信心校準、延遲與成本。
